📱 Aplicaciones Móviles

¡Bienvenido a este repositorio de Aplicaciones Móviles! Aquí encontrarás proyectos y prácticas para aprender a desarrollar apps y videojuegos. 🚀📲

📂 Contenidos

🔹 Unidad 1 - AppInventor

🛠️ Creación de aplicaciones con AppInventor🤖 Introducción a la programación por bloques📲 Desarrollo de apps básicas

🔹 Unidad 2 - Introducción a Kotlin

📝 Fundamentos de Kotlin🛠️ Tipos de datos y estructuras de control🔄 Programación orientada a objetos en Kotlin

🔹 Unidad 3 - Introducción a Jetpack

📦 Uso de Jetpack Compose🎨 Diseño de interfaces modernas⚡ Navegación y gestión del estado

🔹 Unidad 4 - Proyecto Completo

🚀 Desarrollo de una app desde cero🗂️ Gestión de datos y almacenamiento🔗 Integración con APIs

🔹 Unidad 5 - Desarrollo de Juegos

🎮 Introducción al desarrollo de videojuegos🕹️ Motores de juego y físicas🎨 Diseño de personajes y escenarios

🔹 Unidad 6 - Juego Completo

🔥 Creación de un videojuego completo⚙️ Optimización y rendimiento🎯 Publicación y pruebas

Cada carpeta contiene código fuente y ejemplos prácticos para cada unidad. ¡Explóralos y aprende creando! 🏗️
